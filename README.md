# 🎓 InternSphere - Student Internship & Recruitment Portal

InternSphere is a full-stack MERN application designed to streamline the internship application and recruitment process for both students and recruiters.

---

## 🚀 Features

### 👤 For Students
* **Profile Management:** Set up academic details, resume link, and skill set.
* **Job Search & Filter:** Browse active internship listings with real-time filtering.
* **Easy Application:** Apply to internships with one click and track application statuses.

### 💼 For Recruiters
* **Job Posting:** Create, update, and manage internship listings.
* **Applicant Dashboard:** Review student profiles and applications in real-time.
* **Status Updates:** Shortlist, accept, or reject candidate applications seamlessly.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS / CSS3
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT (JSON Web Tokens) & Role-Based Access Control

---

## 💻 Getting Started Locally

* Node.js (v16 or higher)
* MongoDB database instance (Local or Atlas)
